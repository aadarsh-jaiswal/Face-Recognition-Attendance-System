# Face Recognition Attendance System

A Python-based facial recognition system built to automate student attendance tracking. 

**Tech Stack Used:**
* Python
* OpenCV (for face detection)

**Features:**
* Detects and identifies faces in real-time.
* Automatically logs attendance.

**How to Run:**
1. Clone this repository.
2. Run `main.py` (or `gui_main.py`) to start the interface.
